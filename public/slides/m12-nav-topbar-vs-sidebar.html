Which pattern fits — one glance

Top bar wins when

  • Content is marketing / product / docs — shallow tree
  • You have ≤ 7 primary sections the user needs at eye level
  • The reader scans horizontally, not vertically
  • You need a strong CTA anchor on the right of the bar
Real-world: Apple.com, Stripe, Notion homepage, Vercel

Sidebar wins when

  • You're building a tool — SaaS, admin panel, dashboard
  • Users spend hours inside; 10+ destinations exist
  • You need groups / nesting / badges (Inbox 4, Design › Tokens)
  • Screen real estate can be reclaimed via a collapse to icons
Real-world: Figma, Slack, Jira, Linear, GitHub
The Rule of Thumb: use a top bar to sell the product, a sidebar once someone is inside it.
