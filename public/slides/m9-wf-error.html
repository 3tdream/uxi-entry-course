Error state — blame vs help

Say what went wrong, own it, give the next step. No jargon, no blame.

✗Weak error
⚠ ERROR 422
Invalid input. Authentication failed.
Please contact support@example.com
Jargon, blame, no way out. "Invalid", an error code, no instruction. The user feels at fault and bounces.
✓Strong error
Hmm, that password didn't match
Looks like a typo. Try again — or reset your password in one click.
Reset password
What's wrong, we're on it, here's the next step. Trust goes up even on an error — the paradox of good UX copy.
