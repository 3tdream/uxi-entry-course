06

CTA button — generic vs specific

Verb + object + number. The user should see the result before they click.

✗Weak copy
Total$12.60
Shipping in 2 business days
Submit
"Submit" tells the user nothing. A generic verb with no object — they have to guess what happens. Cautious clicks, conversion drops 15–30%.
✓Strong copy
Total$12.60
Shipping in 2 business days
Pay $12.60 →
Verb + object + amount. The user sees the outcome before clicking — a tiny contract. Booking and Shopify logged +12–25% on swaps like this.
07

Error state — blame vs help

Say what went wrong, own it, give the next step. No jargon, no blame.

✗Weak error
⚠ ERROR 422
Invalid input. Authentication failed.
Please contact support@example.com
Jargon, blame, no way out. "Invalid", an error code, no instruction. The user feels at fault and bounces.
✓Strong error
Hmm, that password didn't match
Looks like a typo. Try again — or reset your password in one click.
Reset password
What's wrong, we're on it, here's the next step. Trust goes up even on an error — the paradox of good UX copy.
